# Project
Published version of a semester project on image processing optimization. We used SIMD and eliminatioon of floating point operations as well as optimization transformation of the problem.

# Report
Information about the project structure.

# Presentation
Detailed Presentation of the project with demonstrations of the methods and achieved speedups. Some graphics are in german, because the presentation was in german.

# Testdata

This project uses the **COCO (Common Objects in Context) dataset**:

- Lin, T.-Y., Maire, M., Belongie, S., Hays, J., Perona, P., Ramanan, D., Dollár, P., & Zitnick, C. L. (2014). [Microsoft COCO: Common Objects in Context](https://cocodataset.org). *European Conference on Computer Vision (ECCV), 740–755.*
